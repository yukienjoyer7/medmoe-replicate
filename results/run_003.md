# Run 003 — Paper-Exact Router Architecture (T_i + Per-Layer Routing)

**Date:** 2026-06-12  
**Changes from run_002:** Two architectural fixes matching paper Fig. 2

---

## What Changed

| | run_002 | run_003 |
|-|---------|---------|
| Router input | mean-pooled T_comb (image+text) | **T_i only** (projector output) |
| Router placement | once before LLM, gate_probs broadcast to all 30 layers | **inside each MoEWrapper**, reads `x[:,0:1,:]` per layer |

**Router accuracy: 25% → 81%.** The T_i fix was decisive. Previously, the router was reading mean-pooled T_comb — a mixture of CLIP image features and SmolLM text token embeddings. The text embeddings added noise that swamped the domain-discriminative image signal, leaving the router no better than random. Reading T_i (pure projector output, before any LLM processing) gives the router a clean image feature to classify.

## Inference — Expert Dispatch (MRI sample, layers 0–29)

Key observation: routing **evolves across depth**. Early layers (0–5) use E0 (X-Ray) + E3 (Pathology). From layer 17 onward, the pattern shifts to E2 (MRI) + E3 — the correct domain expert gains dominance in deeper layers as the hidden state accumulates more domain-specific context.

This is qualitatively different from run_002 where all 30 layers showed **identical** dispatch (E0+E2, gate probs exactly 0.25/0.25/0.25/0.25) because a single pre-computed gate_probs was broadcast to every layer.

| Layer range | Dominant pattern | Gate prob range |
|-------------|-----------------|-----------------|
| 0–5 | E0 (X-Ray) + E3 | 0.24–0.27 |
| 6 | E2 (MRI) + E3 | — |
| 7–18 | Mostly E0 (X-Ray), transitioning | — |
| 19–27 | **E2 (MRI) + E3** dominant | E2: 0.27–0.30 |
| 28–29 | Back to E0+E3 | — |

## Key Findings

1. **T_i input was the critical fix.** The router stall in run_001/002 (router_acc ~25%) was entirely caused by reading T_comb. T_i gives clean, domain-separable image features from CLIP; T_comb mixed in LLM text token embeddings which carry no domain signal at 200 samples.

2. **Per-layer routing produces depth-varying expert selection.** Gate probs now range 0.19–0.31 and differ meaningfully across layers, vs uniform 0.25 flatline in run_002. Deeper layers show stronger domain-expert alignment (MRI example: E2 prob rises from 0.25 at layer 0 to 0.30 by layer 19).

3. **Phase 3 lm loss slightly higher** (1.035 vs 0.879). Trade-off: better routing fidelity at the cost of slightly noisier expert training — each layer's routing signal now depends on the evolving hidden state rather than a fixed pre-LLM gate.
