# Run 001 — Paper-Exact Med-MoE Reimplementation

**Date:** 2026-06-12  
**Goal:** Reproduce Med-MoE 3-phase training from scratch to understand the routing mechanism. Not intended to match paper results — small param/data setup on a single RTX 4050 (6GB).

## Phase 2 — Instruction Tuning and Routing

**Trainable:** LLM + router + projector (135.15M) | **Loss:** L_Instr + L_Router | **LR:** 2e-5

| Epoch | lm_loss | router_loss | router_acc |
|-------|---------|-------------|------------|
| 1 | 4.393 | 1.392 | 25.0% |
| 2 | 2.750 | 1.392 | 25.0% |
| 3 | **2.272** | **1.392** | **25.0%** |

**Router completely stalled.** Router loss stays at 1.392 ≈ log(4) = 1.386, meaning the router is outputting near-uniform logits every epoch — stuck at random chance.

**Why:** LR 2e-5 is correct at paper scale (500K alignment samples give T_comb rich domain structure). At 200 samples, T_comb contains almost no domain-discriminative signal in the pre-LLM embedding space, so 2e-5 is far too small to overcome the noise and move the router weights.

LM loss improved normally (4.39 → 2.27), so the LLM itself is learning fine.

**Trainable:** MoE experts + meta-expert (149.30M) | **Loss:** L_MoE | **LR:** 2e-5

| Epoch | lm_loss |

| 7 | 4.355 |

| 9 | **4.040** |

Slow but consistent descent over 9 epochs. The activation spike (epoch 1: 12.92) is expected — `activate_moe()` replaces all 30 FFN layers with truncated weights (intermediate_dim 1536→576). Recovery is slower than previous experiments due to the conservative 2e-5 LR — the model is taking smaller steps per update.

---

## Key Observations

1. **Router stall is a scale problem, not an architecture bug.** The paper's T_comb routing works because 500K alignment samples push domain-discriminative structure into the input embeddings. At 200 samples that signal doesn't exist yet.

2. **Phase 3 converges slowly with 2e-5 LR.** 9 epochs only brought lm from 12.9 → 4.0. Higher LR (3e-4, used in earlier experiments) converged to ~2.1 in 3 epochs. The paper's LR is calibrated for a model that already has strong priors from large-scale pretraining.

3. **Hyperparams are now paper-exact** (epochs, LR, schedule, weight decay). The remaining deviations are hardware constraints: CLIP ViT-B/32 vs CLIP-Large, 200 samples vs ~500K, fp32 vs bf16.
